# Contact-Book-and-Student-Score-Exercise-

## Student Score Exercise
A simple program that generates a class of students with varying academic strength which affects their generated scores for each subject. The students and their scores are stored in a dictionary.

### About
Didn't want to type out individual scores for each student so made a code that generates it. It uses probability weights with the random module to give a more realistic scores. The class also has its probability weight for student generation, that helps in making a class with a more realistic distribution of students and their academic strength, with the average strength being more dominant. 
I also made a statistics function that displays the highest, lowest and mean scores per subject. There's also a function that gives the student(s) that scored the highest and the top score.
### Used
- Dictionaries, tuple and lists.
- Rich module for color coding scores and better presentation.
- Random module for score and student generation.
